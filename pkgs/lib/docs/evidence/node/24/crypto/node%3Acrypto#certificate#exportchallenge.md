## Conclusion

Intrinsic synchronous errors:

- `TypeError` / `ERR_INVALID_ARG_TYPE`: input is neither primitive string nor genuine buffer source.
- `TypeError` / `ERR_UNKNOWN_ENCODING`: string input and an unrecognized nonempty primitive string encoding (even when input is empty).
- Uncoded `TypeError`: invalid input's diagnostic formatting can encounter a revoked/invariant-violating proxy, a primitive RHS of `in`, Symbol-to-string conversion, or unsuccessful primitive conversion.
- `RangeError` / `ERR_OUT_OF_RANGE`: nonempty native input byte length exceeds `INT_MAX` (`2**31 - 1`).
- Uncoded `RangeError`: custom inspection hooks returning each other's objects make Node's diagnostic traversal overflow; neither hook throws or recursively calls itself.
- Uncoded `ReferenceError`: reading an uninitialized exported `constructor` binding from an actual ESM namespace during invalid-input diagnostic construction.
- Exact base `Error` / `ERR_INTERNAL_ASSERTION`: a custom inspection result can be a function whose non-string `name` is a namespace. Function-name inspection omits the recursion counter and bypasses the normal depth cutoff. A namespace export's inspection hook throwing a non-ReferenceError value then triggers Node's internal assertion instead of propagating that value.

Invalid-input diagnostics read `constructor`, `constructor.name` or function `name`, use `in`, stringify names, and may run custom inspection. Supplied exceptions/values generally propagate, but namespace formatting can replace them with `ERR_INTERNAL_ASSERTION`. The getter `Error` and custom-hook `SyntaxError` repros are propagation; the separate namespace-formatting `Error` repro is intrinsic. None is an OpenSSL error. No promise, iterator, callback-delivery or event channel exists. The method ignores its receiver and does not convert arbitrary objects into SPKAC strings. Encoding objects are ignored, not coerced. Non-string input bypasses encoding validation. Malformed SPKAC returns the empty string, not an OpenSSL exception (and this exposes a declaration return-type mismatch).

Scope: official Node 24.19.0 Linux x64, OpenSSL 3.5.7, V8 13.6.233.17-node.51, sandbox disabled; normal unmodified built-ins, writable default `Error.stackTraceLimit`, sufficient memory. Process/OOM failures and hostile mutation of global built-ins are excluded per auditing policy. BoringSSL/32-bit/custom embedder builds are not certified by this run. The source BoringSSL branch only trims trailing whitespace before the same decoder path; it does not add a JavaScript exception. On 32-bit builds the buffer allocation limit can prevent construction of an over-INT_MAX argument; that would be a fixture failure, not this callable throwing.
