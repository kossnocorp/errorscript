## Conclusion

**Default mode has no ordinary throwable effects**, including for nullish, primitive, unrelated, proxy, or revoked-proxy receivers. The receiver is a Map **key**, not the Map receiver and not subject to a private-field check. It is never accessed or coerced. No arguments are consumed.

**Legacy flag mode has synchronous intrinsic TypeError** for nullish property access, revoked/invalid proxies or their invariant violations, and failed strict assignment (including read-only `enabled`, missing setter, or falsy proxy `set`). It also has **synchronous intrinsic ReferenceError** when the `enabled` lookup reaches a module namespace export whose lexical binding is uninitialized. This includes direct namespace receivers, inheritance from a namespace, and forwarding proxies. Receiver getters/setters and proxy operations can propagate **any value** synchronously. `Error` and `SyntaxError` repros demonstrate supplied errors, not constructors called by Node. An ordinary unmodified instance with intact bookkeeping has no ordinary error in either mode. There is no promise/rejection, iterator, or error-event channel. Last-hook removal can enqueue internal promise-hook cleanup; it introduces no user callback or ordinary deferred error. Default frame mode still never reads the namespace export, even before initialization.

Scope: Linux Node v24.19.0, its shipped V8, standard host intrinsics and intact private context/hook bookkeeping. Includes adverse receivers and their property behavior; excludes replacing the built-in, tampering with Node's private context frame or hook machinery, global prototype/primordial replacement, native-addon corruption, resource/stack exhaustion, and process termination. This is not a claim about unrelated async-hook callback delivery (which can terminate Node).

### Legacy implementation: read, conditional write, storage/hook removal

[Legacy ALS source, lines 22–31, 45–56, 69–87](https://github.com/nodejs/node/blob/cdc1b38d40cb567b7ad0b39c86addf830a0af0ae/lib/internal/async_local_storage/async_hooks.js#L22-L87): constructor creates writable `enabled`, then `_enable()` registers the instance. `disable()` is exactly `if (this.enabled) { this.enabled = false; ... }`, followed by `ArrayPrototypeIndexOf(storageList, this)`, `ArrayPrototypeSplice(storageList, index, 1)`, and `if (storageList.length === 0) { storageHook.disable(); }`. Other primitives box without coercion. [ToBoolean](https://tc39.es/ecma262/#sec-toboolean) (5084–5101) tests the result without `valueOf`/`toString`; a falsy result exits, a truthy result proceeds to assignment.
- **Module namespace ReferenceError (cross-review correction):** [Module namespace exotic `[[Get]]](https://tc39.es/ecma262/#sec-module-namespace-exotic-objects-get-p-receiver), spec lines 15717–15731 at the pinned ECMA-262 revision, resolves the exported string property to a binding, throws ReferenceError if its target environment is empty, otherwise does `Return ? _targetEnv_.GetBindingValue(_binding_.[[BindingName]], *true*)`. Ordinary inherited lookup and a proxy with no get trap also reach that exotic operation. Once initialized to false, the same three receivers return normally.
