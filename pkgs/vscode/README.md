# ErrorScript for VS Code

ErrorScript infers errors in your TypeScript and JavaScript code and shows them in your editor.

- See inferred errors in hover information.
- Check error contracts with `Returns<Value, Error>`.
- Get diagnostics for unhandled errors.

Select an **ErrorScript** language mode using VS Code's language picker to get started. The extension includes the ErrorScript compiler.

Learn more at [errorscript.org](https://errorscript.org).
